# Econometria Aplicada a Finanças — 2026

Este repositório reúne as atividades práticas e avaliações desenvolvidas durante a disciplina **Econometria Aplicada a Finanças**, do **Mestrado Profissional em Administração**.

O objetivo é documentar as resoluções dos exercícios, organizar os códigos utilizados nas análises econométricas e registrar a aplicação dos conceitos estudados ao longo da disciplina.

## Organização do repositório

- **`atividades/`**: resoluções das atividades práticas, organizadas individualmente e acompanhadas dos respectivos arquivos-fonte e, quando disponíveis, relatórios em HTML.
- **`avaliacoes/`**: trabalhos e avaliações desenvolvidos durante a disciplina.
- **`data/raw/`**: bases de dados utilizadas nas atividades e análises.
- **`ecnt2026-jonathan.Rproj`**: arquivo do projeto para abertura no RStudio.

## Tecnologias utilizadas

- **R** — linguagem utilizada para programação e análise estatística.
- **Quarto** — elaboração e renderização dos relatórios com código, resultados e interpretações.

## Como utilizar

Os relatórios em HTML podem ser consultados diretamente pelo navegador.

Para visualizar ou reproduzir as análises, é necessário ter o R e o Quarto instalados, além dos pacotes utilizados em cada atividade. O projeto pode ser aberto pelo arquivo `ecnt2026-jonathan.Rproj` no RStudio.

Para renderizar um documento individual, utilize o comando:

```bash
quarto render caminho/do/arquivo.qmd
```
